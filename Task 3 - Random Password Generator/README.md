# Random Password Generator

## Description
A simple Python program that generates a random and complex password based on the length entered by the user.

This project uses Python's built-in random and string modules to generate passwords containing letters, numbers, and special characters.

## Technologies Used
- Python

## Key Concepts
- Importing modules
- random module
- string module
- String manipulation
- User input and output
- Random character selection
- for loop

## How to Run
1. Make sure Python is installed.
2. Open the project folder in your terminal.
3. Run the following command:

```bash
python password_generator.py
